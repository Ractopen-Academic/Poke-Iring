# Security Policy

## Supported Versions

Only the current primary branch and latest tagged release receive active security updates.

| Version | Supported |
| :--- | :--- |
| `main` (trunk) | Yes |
| < 1.0.0 | No |

---

## Reporting a Vulnerability

The Poke: Iring development team takes security and privacy seriously, particularly regarding player location coordinates, authentication tokens, and user camera feeds.

If you believe you have discovered a security vulnerability in Poke: Iring, please follow responsible disclosure guidelines:

1. **Do not disclose the issue publicly** through public GitHub issues, discussions, or social media.
2. Submit a private report via **GitHub Private Vulnerability Reporting** on the repository page:
   `https://github.com/Ractopen-Academic/Poke-Iring/security/advisories/new`
3. If private reporting is unavailable, reach out directly to the project maintainers via GitHub security advisories or by opening an issue requesting a private security contact.

### What to Include

To help us investigate and resolve the issue quickly, please provide:
- A clear description of the vulnerability.
- Proof of concept or reproduction steps.
- Affected components (e.g. Firebase rules, GPS coordinate handling, camera privacy, dependency version).
- Assessment of potential impact and suggested remediation if known.

### Response Timeline

- **Initial acknowledgment**: Within 48 hours.
- **Triage & severity assessment**: Within 5 business days.
- **Patch & disclosure schedule**: We aim to release a fix promptly and coordinate public disclosure once the patch is verified.
